REVIEW.md: Starter Code Defect Log
#	Where (function / line)	What is wrong	How you'd notice it (test, input, or symptom)	How you fixed it
1	health()	Returns {"status": "ok"} without checking database connectivity.	Stop MongoDB or pass invalid MONGO_URI; GET /health still returns HTTP 200 instead of 503.	Execute db.command("ping") in a try-except block; raise HTTPException(503) if ping fails.
2	create_employee()	Uses non-atomic find_one then insert_one check-then-insert.	Send concurrent POST /employees with identical emp_code; both pass check and insert duplicates.	Created database unique index on employees.emp_code at startup; catch DuplicateKeyError and return 409.
3	create_employee() / EmployeeIn	created_at set to naive local time; returned as ISO/datetime instead of epoch millis. Shift times equality unvalidated.	POST /employees response contains ISO string datetime instead of integer epoch millis int. Identical shift_start/shift_end allowed.	Validate shift_start != shift_end. Store UTC datetime, and format created_at as integer epoch milliseconds in API responses.
4	list_employees()	Pagination formula skip = page * page_size skips first page of results.	Request GET /employees?page=1&page_size=20; skips first 20 records and returns empty array.	Fixed formula to skip = (page - 1) * page_size.
5	list_employees()	db.employees.count_documents({}) ignores query filters, and missing emp_code sort.	Filter by department=Engineering; returned total counts all employees across all departments. Output unordered.	Passed q filter to count_documents(q) and added .sort("emp_code", 1) to MongoDB query.
6	punch_in()	Unhandled AttributeError (HTTP 500) if employee does not exist.	POST /attendance/punch-in with non-existent emp_code; crashes with 500 error accessing emp["shift_start"].	Added explicit if not emp: raise HTTPException(404, "Employee not found").
7	punch_in()	Uses find_one then insert_one check-then-insert; race condition under concurrency.	Send two parallel POST /attendance/punch-in for same employee/date; both succeed with 201.	Created compound unique index on {emp_code: 1, date: 1}; catch DuplicateKeyError and return 409.
8	compute_late_minutes() & punch_in()	Assumes naive local time; ignores subsecond truncation (R1), overnight shifts (R1), and boundary rules (R2).	Punch in at 01:30 IST for shift 22:00-06:00; assigns date to 2026-07-07 instead of shift date 2026-07-06. Subseconds cause rounding drift.	Truncate instants to whole seconds, handle IST timezone (UTC+05:30), compute overnight shift attendance dates and shift start/end IST bounds.
9	list_attendance()	Loads entire collection into Python memory with list(db.attendance_logs.find(q)) and sorts in Python. Missing secondary sort.	High latency and memory spike on 100k documents. Returns incorrect sort order (date desc only).	Applied .sort([("date", -1), ("emp_code", 1)]), .skip(), and .limit() directly at the MongoDB query level.
10	compute_work_hours() & analytics	Standard Python round() uses round-to-even (banker's rounding) instead of half-up rounding (R4, R8).	Calculating work hours or rates with .005 or .5 fractional component rounds down instead of up.	Built custom half_up_round() helper using decimal.Decimal with ROUND_HALF_UP.
11	punch_in() & list_attendance()	Mutates internal _id into an "id" field in JSON response, violating schema.	OpenAPI contract validation fails due to unexpected "id" field and non-integer epoch millis dates.	Built format_attendance_doc() helper to strip internal _id and convert BSON datetimes to epoch millis ints.
12	compute_overtime()	Date string parsing in datetime.fromisoformat(date_str) fails timezone integration and overnight shift end calculation.	Overtime for overnight shift crossing midnight calculated against wrong date/day bound.	Built compute_shift_instants() returning exact IST shift start and shift end datetimes handling overnight dates.
